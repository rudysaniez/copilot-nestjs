# copilot-nestjs

Backend starter built with NestJS.

## Installation

```bash
npm install
```

## Run the project

```bash
npm run start:dev
```

The API starts on `http://localhost:3000`.

## Validate

```bash
npm run build
npm test
npm run test:e2e
```
